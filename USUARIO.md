# 🚀 Nexus Workspace

Um aplicativo de desktop moderno, leve e elegante para gerenciamento de tarefas diárias, desenvolvido em **Python** utilizando **Flask**, **Pywebview** e **SQLite**.

---

## ✨ Funcionalidades

- **Interface Moderna (Dark Mode):** Visual limpo, inspirado em ferramentas de produtividade modernas, com foco em experiência de usuário.
- **Persistência de Dados (SQLite):** Suas tarefas são salvas automaticamente em um banco de dados local integrado.
- **Alertas de Prazo Dinâmicos:** O sistema calcula o tempo restante para o seu *deadline* diário e altera as cores dinamicamente (Seguro 🟢, Atenção 🟡 e Atrasado 🔴).
- **Busca em Tempo Real:** Filtre rapidamente suas tarefas ativas digitando qualquer termo ou categoria.
- **Experiência Nativa de Desktop:** Roda como um aplicativo independente de desktop, sem a necessidade de manter o navegador aberto.

---

## 🛠️ Tecnologias Utilizadas

- **Python** (Lógica principal do backend e servidor)
- **Flask** (Micro-framework web para as rotas da API)
- **Pywebview** (Empacotador para transformar a aplicação web em um app de desktop nativo)
- **SQLite** (Banco de dados leve e embutido)
- **HTML5, CSS3 & JavaScript (Vanilla)** (Interface de usuário responsiva e dinâmica)
